FFT ALGORITHM
-------------
Here is example of the FFT algorithm, you need to do the same logic, in CUDA (utilizing parallelism).
The IFFT isn't given here, but you need to implement it too
(you may write single function that gets a true/false flag for the invert property)
```
def fft(x: Sequence[complex]) -> List[complex]:
    N = len(x)
    # ----- Base case -------------------------------------------------------
    if N == 1:
        return [x[0]]

    # ----- Validate length -------------------------------------------------
    if (N & (N - 1)) != 0:                # N is not a power of two?
        raise ValueError("FFT requires the input length to be a power of 2")

    # ----- Split into even and odd indexed elements ------------------------
    even = fft(x[0::2])    # samples at indices 0,2,4,...
    odd  = fft(x[1::2])    # samples at indices 1,3,5,...

    # ----- Combine the two halves -------------------------------------------
    # twiddle factor: exp(-2*pi*i * k / N)
    combined = [0] * N
    for k in range(N // 2):
        t = cmath.exp(-2j * cmath.pi * k / N) * odd[k]
        combined[k] = even[k] + t # lower half
        combined[k + N//2] = even[k] - t # upper half
    return combined
```
